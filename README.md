# Sushi Mir — виправлена версія для Netlify

## Що виправлено
- Додано відсутню серверну функцію `netlify/functions/catalog.js`.
- Спільний каталог товарів зберігається в Netlify Blobs.
- Додавання, редагування, видалення, очищення та відновлення каталогу записуються на сервер і стають доступними всім відвідувачам сайту.
- Відкриті сторінки перевіряють оновлення каталогу приблизно кожні 15 секунд.
- Фото товарів зберігаються разом із каталогом.
- `app.js` та `bot.py` не змінювалися. Telegram-надсилання замовлень залишене без змін.

## Як опублікувати на Netlify
1. Розпакуйте ZIP. Файли `index.html`, `app.js`, `styles.css`, `package.json`, `netlify.toml` та папка `netlify` лежать одразу в корені архіву.
2. Завантажте ці файли в корінь GitHub-репозиторію, який підключений до вашого сайту Netlify. Не завантажуйте ZIP як один файл і не кладіть усі файли в додаткову вкладену папку.
3. Зробіть commit/push. Netlify має автоматично запустити deploy. Дочекайтеся статусу **Published**.
4. У Netlify за потреби відкрийте Site configuration → Environment variables і додайте `ADMIN_PASSWORD` зі значенням чинного пароля адмін-панелі. Якщо змінну не додати, функція використовує поточний пароль із сайту.
5. Після зміни змінних середовища запустіть новий deploy.

`netlify.toml` вже містить потрібні налаштування: Publish directory `.` та Functions directory `netlify/functions`. `package.json` встановлює `@netlify/blobs`. Окремо створювати базу даних не потрібно.

**Важливо:** просте перетягування статичних файлів через Netlify Drop не розгортає Netlify Functions. Потрібен deploy через підключений GitHub-репозиторій або Netlify CLI.

## Перевірка
1. Відкрийте сайт у двох браузерах або на двох пристроях.
2. Увійдіть в адмін-панель, додайте або видаліть товар.
3. На другому пристрої зміна має з'явитися автоматично приблизно протягом 15 секунд або після оновлення сторінки.

Кошик і тема оформлення залишаються локальними для кожного відвідувача. Telegram-бот не перероблявся.
